# stavewise-web

## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues of the main repo `wasseramseleo/stavewise` (always `gh issue … -R wasseramseleo/stavewise`), not in `stavewise-web`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
